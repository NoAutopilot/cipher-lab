# Images: BL Cotton MS Caligula C II, f. 277r-v

Fetched 21 September 2026 from the British Library's IIIF image service
(`bl.digirati.io/iiif/ark:/81055/vdc_100162985756.0x000001`), the same route
`cyphersolver/norfolk1570/fetch.py` uses. `manifest.json` records the canvas for each file and the width
saved. `fetch.py` here regenerates them.

**Rights.** These are the British Library's digitisations of a manuscript in its collection. The Library
publishes most of its manuscript images for research use and asserts no new copyright over faithful
reproductions of out-of-copyright originals, but it does set its own terms of use, and those terms, not this
note, govern. They are kept here for research on this target. **Check the Library's current terms before
reproducing any of them outside this repository, and before this repository is ever made public.**

**Credit** the British Library and the shelfmark in anything that uses them: BL Cotton MS Caligula C II,
f. 277r-v.
