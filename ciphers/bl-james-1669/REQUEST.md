# Copy request — British Library Add MS 21483, ff.1-8

**Status:** waiting on you. Stage 2 (verified unsolved) — see NOTES.md's Check-solved section, 25 Sept 2026
(LANE CX), which closed both standard-edition checks the QUEUE row named (Clarke's *Life of James the Second*
1816, and Calendar of State Papers Domestic, Charles II, Oct.1668-Dec.1669), both negative.

**What to request:** page images (or a scan) of British Library, Western Manuscripts, **Add MS 21483, ff.1-8**
only — the 1669 item catalogued as "Anonymous letters, in cipher: 1669 ... partly in cipher, on political
affairs, with a key to some of the names." This is the smallest useful set: the volume's other nine items
(1685-1688 political correspondence, Melfort, the Abbess of the English Benedictines at Ghent, a letter
involving Eleanor "Nell" Gwyn) are a different cluster and are not requested here.

**Why this set:** ff.1-8 carries both the 1669 ciphertext *and* its own partial key to names, bound in the same
folios — the cheapest possible route to a reading, per the QUEUE row's own assessment (NOTES.md, "Next").

**Not digitised.** Not on the British Library's public IIIF/digitised-manuscripts route (dead since the 2023
cyberattack, per CLAUDE.md's host table). `searcharchives.bl.uk`'s catalogue API is reachable for item-level
metadata but carries no image link for this item.

**Order via (checked 25 Sept 2026):** the British Library's Imaging Services online order form
(`forms.bl.uk/imaging`) or by email to `itemrequests@bl.uk`, quoting Add MS 21483, ff.1-8. Note found this
date on the BL's own manuscripts-requesting guide: the Library "is unable to provide scanned copies from
original manuscripts" except from an existing surrogate (microfilm), so the reply may be that ff.1-8 can only
be seen in person with a Reader Pass (`bl.libguides.com/reference-services/manuscripts/requesting-items`) —
ask whether a microfilm surrogate exists for Add MS 21483 before assuming a reading-room visit is required.
