# PREREG: Tomokiyo's Colbert-Gravel 1672 key (Mel. Colbert 159 f.102) tested on R2678 (R9-DEC2678C, 6 Oct 2026)

Written 6 Oct 2026 ~06:47 UTC (date -u), pushed before `gravel1672_test.py` is run.

**Disclosure (rule 3 honesty).** Before writing this file the worker had both the key table and R2678's 13 cipher groups
on screen (the key image was fetched to read it; the groups were re-read from a native crop of canvas 356 to settle the
diacritics). An informal by-eye application was therefore possible before this file existed and it was seen. The gate below
is mechanical (a script, fixed nulls, fixed thresholds) so that look cannot move the numbers, but the choice of test was
made after it. A reader should weigh the result with that in mind.

**Key.** Satoshi Tomokiyo's published reconstruction, "Colbert-Gravel Cipher (1672) (DE=23_)", cryptiana.web.fc2.com/code/louisxiv0.htm,
image `louisxiv_0gravel1672.png` (snapshot unmodified at sources/cryptiana/keys/img/), built by him from the period interlinear
decipherment of Mel. Colbert 159 f.102 (abbé Jacques de Gravel to Colbert, 23 Apr 1672). Key source class: published (credited,
rule 8). Transcribed cell by cell into `key_gravel1672.tsv` (code + mark: `^` overline, `_` underline, `'` prime, plain none);
Tomokiyo's bracketed (inferred) cells carry grade M.

**Ciphertext.** `ciphertext.tsv`, this worker's read of f.349r from the native crop
`images/src_ark_12148_btv1b10035540v_f356_4800_4950_3500_800.jpg`: P1 `29`; P2 `80 62 41 73_ 22: 51` (`:` = two points);
P3 `48^ 93 71 37 60^ 92 58^ 0`. (passA.tsv's "73 3^(2) 51" is re-read here as 73 underlined + 22 pointed; passA is unchanged.)

**Decode.** `tools/decode_key.py` on exact (code, mark) cells only. A token with no exact cell is unkeyed (U), not guessed.

**Statistic.** T = mean per-letter log10 trigram probability (add-one, 26 letters, trained on tools/data/fr17) of the
letters decoded from P2+P3 (P1 is one nomenclature-shaped group and is excluded; unkeyed tokens are skipped).

**Controls, each able to differ from the target on T:**
1. Shuffled key (2000): the value column of key_gravel1672.tsv permuted across rows (same cells, same coverage -- coverage is
   not the statistic; the values, hence the letters, change). p1 = share of shuffles with T >= real.
2. Shuffled target (2000): token order permuted within P2 and within P3, decoded with the real key. p2 likewise.
3. Power (matched synthetic, same design, N, language): 200 random fr17 spans enciphered with key_gravel1672.tsv (greedy
   longest match over the key's syllable and letter cells) to exactly 14 tokens (R2678's P2+P3), then T and control 1 (500
   shuffles each). Power = share with p1 < 0.05.

**Gate.** PASS iff p1 < 0.05 and p2 < 0.05. A FAIL counts as a negative on the 1672 key only if power >= 0.80; below that it
is a non-test at this N. Descriptive (not gated): of R2678's marked tokens, how many have an exact cell with the same mark.

**Grades.** Only if PASS: H for a token whose exact unbracketed cell is read; M for a bracketed cell; U unkeyed. On FAIL every
token is M or U and no reading is claimed. A 1672 key on a 1665 letter may not fit; a FAIL is a result.

Clarification before the run: where a plain code has both an attested alphabet value and a bracketed (inferred) syllable value
in Tomokiyo's table (31, 51, 71, 82, 91), the attested alphabet value is the key cell; 43 (z? / [je]) stays ambiguous, M.
