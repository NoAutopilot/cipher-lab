## Why this pool, and in this order

SP 106/6 no. 32 — the Chauran/Wickfort French encoding table — is now in hand as `key.tsv` in this folder
(grade H, read from DECODE's own 2020 transcription of two period copies, records 509 and 506). It has not yet
been applied to anything: none of the 18 letters below is digitised. The minimum order gets one Group A letter
(a known-plaintext control, already PRO-decoded, so the key can be checked against it) and the one Group B
Wickfort letter nearest it in date, so the first TNA order answers the open question — does key.tsv actually
read a real letter — before paying for the other nine.
