# c.127 working sign labels (A2-FLO3, 3 Oct 2026)

Provisional ASCII labels for the symbol cipher of ASFi Dieci di Balìa Responsive filza 8 c.127 (DECODE R3766), drawn
up by A2-FLO3 from the line-crop debug overlay of lines 6-9 only. **Not a settled alphabet** (CLAUDE.md Usage 6: a
settled inventory is the owner's sign sorter's job); it exists only so two blind passes write the same token for the
same form. A pass that meets a form not listed writes `?` plus a short description in brackets, e.g. `?[circle with
cross]`.

| label | form |
|---|---|
| `O` | large circle with a smaller circle or dot inside (target-like) |
| `F` | small circle with a vertical stroke through it (phi-like) |
| `o` | small plain circle, no stroke |
| `/` | division-sign-like mark: short horizontal bar with a dot above and below (often right after a small `o`) |
| `:` | the same bar with two or more dots above and below, or a bar crossed by dotted strokes (looks like `#` with dots) |
| `q` | q / 9-like form: loop with a descender |
| `4` | 4-like form |
| `2` | 2-like form |
| `z` | z / 3-like form with a tail (yogh) |
| `7` | 7-like form |
| `8` | 8-like form (two stacked loops) |
| `a` | alpha / fish form, loop open to the right (like the Greek alpha or a proportional sign) |
| `D` | small triangle (delta), often written raised after another sign |
| `^` | inverted V (caret / lambda without crossbar) |
| `A` | inverted V with a crossbar (capital A) |
| `p` | pi form: horizontal bar on two short legs (sometimes a second bar) |
| `u` | u / v-like open cup |
| `t` | cross / dagger / plus, including a cross on a baseline stem |
| `#` | three vertical strokes joined by a bar or bars (a tally / comb) |
| `H` | H-like form (two uprights and a crossbar) |
| `I` | single upright with serifs or a bar top and bottom (Roman I) |
| `x` | X / asterisk-like crossed form |
| `~` | tilde / wave |
| `<` | less-than / open angle |
| `n` | eta / n with a descender |
| `-` | a long flat horizontal stroke standing alone as a sign |

Clear Italian words written among the cipher (e.g. `chomunita`, `che`, `egli`) are copied as words, prefixed `=`
(`=chomunita`). Word or line breaks are not tokens; one token per sign, space-separated.
