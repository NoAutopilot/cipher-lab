# V-OLD-O5 eye-check rule (written 10 Oct 2026, 03:2x UTC by date -u, before any S word was selected or any crop viewed)

Population: S-graded cipher tokens (grade == S, raw token contains a digit) on leaves L4 and L7 in `reading_L457_tokens.tsv`
(OLD-O2's registered grades), in file order. L5 is excluded (no masked O2 crop; its crops are OLD-SIBS's).
Selection: the 7th, 14th, 21st, ... S token of that ordered list, the first 20 so selected (145 S tokens expected -> 20 picks).
Check: the verifier views the masked O2 line crop (`images/crops_O2/<prefix>_Lnn.jpg`) holding the token and records, sign by
sign, whether the image shows the reconciled digit string: agree / disagree (which sign) / cannot tell. Key-aware verifier, so
this is a check of sign identity, not a blind read; it regrades nothing.
