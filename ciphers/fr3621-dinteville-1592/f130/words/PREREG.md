# DIN-WORDS pre-registration (account 1, LANE-A1, 3 Oct 2026, written before any segmentation is scored)

Brief: `.claude/briefs/runs/2026-10-03-acct1-din-words.md`. Target: f.130r, decode.json job 4 (print key at strict grades,
`f130/print/key_dk_strict.tsv`, C 177 / M 311 / U 39). No key value is changed by this job.

## Input
- Tokens: `f130/ciphertext_dk.tsv` (559 rows). `CLEAR:` rows and `.` rows are forced word breaks and are not scored
  (527 cipher tokens remain, the same 527 as job 4). Line ends are NOT breaks (a word may run over a line end, as in the
  hand); the clear spans are.
- Letter per token: the job-4 key value, except four polyphone rows, which offer a candidate set:
  `hash` {c, d}, `v` {a, t}, `m` {u, t}, `0` {e, s, p, c} (NOTES.md DIN-PRINT/DIN-FIRM/DIN-LEFT). Key value first; a
  non-key choice costs +0.3 (log10 units).
- U tokens (`v'`, `0'`, `NEW:*`): wildcard, any of the 18 letters the key uses, +1.0 per wildcard inside a word.

## Method
- Word list: `tools/data/fr16/*.txt.gz` (3 files), normalized as `verify/verify_din2.py`'s `norm()` (lower case, accents
  stripped, j->i, v->u, y->i, every non-letter a break, so elisions l', d', qu' become words l, d, qu). Words with corpus
  count >= 2 are kept. Word cost = -log10(count / total word tokens). Max word length 16.
- Segmenter: Viterbi DP over each cipher run (between forced breaks). A step is either a dictionary word whose letters each
  lie in its token's candidate set (cost = word cost + choice penalties), or one undivided letter (junk, cost 6.0, key value).
  The best path fixes both the division and every polyphone/wildcard choice. Ties: first found (deterministic).
- **Divided word (the statistic):** a token counts as divided when the best path places it in a dictionary word of length
  >= 3. Statistic D = divided tokens / 527. One- and two-letter words (elisions, de, le, et ...) may be used by the path but do
  not count toward D.

## Controls (rule 3: the statistic depends on the letter values, so a value-permuting control can differ)
1. **Shuffled key (primary), 200 draws, seed 20261003:** the 29 keyed sign rows' (key value, candidate set) pairs are
   permuted among the signs (the alternates travel with their row, so the control has the same polyphone freedom); U
   tokens and breaks unchanged; same segmenter; D recorded.
2. **Wrong-text keys (secondary), 20:** the 20 wrong-text keys of VERIFY-DIN2 (`verify/verify_din2.py` section 3, seed
   52001, regenerated by importing its functions, not stored on disk before). Calibration: their f.130 n-gram scores must
   reproduce result2.json `wrong_text_f130` max -1.4399 to 4 decimals, or this control is reported as not reproduced and
   not used. Each wrong-text key gives the four polyphone signs as many candidates as the real key does (top-k of that
   sign's alignment counts).

## Gate (fixed now)
PASS = real D above the shuffled-key max (0/200 >= real) AND above the shuffled-key p95 by >= 0.10 ("markedly fewer"),
and, if the wrong-text control reproduced, above its max (0/20). Otherwise the division is reported as not separated from
its control and the reading file carries that warning in its header. Both numbers are reported side by side either way.

## Grades in the output (rule 4)
Every polyphone token's chosen letter is graded I (a contextual choice), whether or not it equals the key value; every U
token placed in a word gets its chosen letter graded I; U tokens left undivided stay U ('?'). Every inserted division is
an I-grade interpretation (counted, not per-token). Other letters keep C/M. Undivided letters are shown inside {..}.

## Judge
`tools/judge_plaintext.py f130/words/judge_spec.json --file f130/words/judge_input.txt`: spec = language fr (fr16),
cipher-part letters only (clear words excluded, chosen letters, U undivided dropped), min_word_cover 0.6. Pasted as is
(PASS or FAIL) into NOTES.md.
