# Copy request — British Library Harley MS 287

**Status:** waiting on you. Partial, not open — see NOTES.md's Verdict: Bourdeau's project (`cyphersolver`,
MIT code / CC BY 4.0 text) has already produced real partial readings across most of DECODE R8477-R8496
(needham1587 ~98% read; harley287 read in sense throughout with named gaps; cobham1588 about a third read),
citing key-recovery from contemporary glosses in the volume itself, not a printed source. This request is for
finishing/verification of that existing partial key, not a fresh cryptanalytic campaign.

**What to request:** page images of British Library, Harley MS 287, covering the three DECODE clusters in this
volume:
- **ff.39-40** (Francis Needham to Walsingham, 28 July 1587; DECODE R8479) — 98% read, one word unresolved.
- **f.11** and **ff.70r-72v** (Lord Cobham at Ostend to Walsingham, 20 and 22 March 1587/8; DECODE R8477,
  R8482-R8487) — read in sense throughout; open items are one code number (42), one code sign (".7."), one
  Jesuit's surname, one verb, and scattered words.
- The Cobham-to-Walsingham folios for **DECODE R8490, R8492, R8495, R8496** (5 May-9 June 1588; folio numbers
  not given in Bourdeau's own notes — ask the Library to identify them from the DECODE record range if the
  request needs a specific folio) — about a third read; several signs remain unglossed or polyphonic.

**Why images, not a fresh attack:** the open items above are named, specific gaps (a handful of signs and
words), not an unbroken cipher — the image is needed to check candidate readings against the actual ink, not
to restart the cryptanalysis (rule 2, image over transcription).

**Order via (checked 25 Sept 2026):** British Library Imaging Services online order form
(`forms.bl.uk/imaging`) or email `itemrequests@bl.uk`, quoting Harley MS 287 and the folio ranges above. Note
found this date: the Library states it "is unable to provide scanned copies from original manuscripts" unless
a microfilm surrogate exists — ask about a surrogate before assuming a reading-room visit (Reader Pass) is the
only route.
