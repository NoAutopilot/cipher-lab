# Pietro de Pusterla 1447 cipher: working labels (SFZ-P, 7 Oct 2026)

Pusterla's sign inventory differs visibly from Amidani's (no plain +, 7, 8-as-number, phi; frequent ÷, barred h, "fo").
These labels are a separate namespace; when cited beside labels.md, prefix them `p:` (e.g. `p:÷`). Where a shape
matches an Amidani label, the concordance column gives it (used for the S1 shared-key test; weak where marked ?).
One token per sign; signs that look like two or three letters ("fo", "gto", "pez") are written as ONE token.
A sign that fits none: N1, N2 ... with a one-line description at the end. Unreadable: `?`.
