## Image audit

Re-examined original frames M34-014-0030 through 0033 and Tomokiyo's
graphic inventory. Frames 0031 and 0032 show the same pair of leaves in
different captures; they are not additional ciphertext. Selected ten
positions in passages p1e, p1f and p3h with two defensible shape labels.
Examples are a curved hook versus a two-lobed sign, a long turned stroke
versus a dash, and shallow waves with uncertain cup counts.

`alternatives.tsv` identifies each position by passage and one-based
glyph index, ignoring `|` reset marks. `image_evidence.json` anchors each
judgment to a line crop, bounding box and source-image hash. The alternatives
are the same reader's provisional judgments. They have not been independently
reconciled and do not exhaust the transcription's uncertainties.

The old first-page line crops begin at original x=250 and can omit signs
at the left edge. Those edges were checked against the full original
frame instead. The ten selected positions have anchors inside the existing
crops. Component numbers generated by `audit_lines.py` are image locators,
not cipher identities; stray ink and multi-stroke signs require visual
inspection. The old transcription was not overwritten.

## Known-answer test

The new search jointly chooses an alphabet and the listed binary label
alternatives. It otherwise retains the earlier model: 24 normalized English
letters, at most two glyph types per letter, historical four-gram scoring,
and the same reset positions. A change from the original label costs 0.3
log10 units, fixed before the target run. Ten binary positions permit
1,024 possible transcriptions. This is a noisy alphabet model, not Annet,
Taylor, or a full word/syllable code.

Two new held-out Jefferson samples have the same 257-token, 36-type and
fragment-length dimensions. Each has ten two-way ambiguities at the same
positions and five deliberately wrong first choices. The hidden true label
is among the alternatives. The target's symbol frequencies and actual
error process are unknown and need not match these controls.

| Control | Fixed labels | Joint labels | Planted errors corrected | New incorrect label changes |
|---|---:|---:|---:|---:|
| 4 | 250/257 letters (97.28%) | 256/257 (99.61%) | 4/5 | 0 |
| 5 | 234/257 letters (91.05%) | 257/257 (100%) | 5/5 | 0 |

Each search used 1,000 restarts × 90,000 iterations. Joint searches warm
started half their runs from perturbed fixed-search candidates, so the
letter-recovery difference is not a clean ablation of alternatives alone.
The direct error-restoration counts demonstrate the new operation.
Both controls passed the prospectively recorded gate in `PROTOCOL.md`:
at least 95% letter recovery and at least four of five wrong labels restored.

## Reproduce

From this directory (Python, NumPy, and a C++17 compiler):

```sh
python prepare.py
python run.py controls
python run.py target
python summarize_target.py
```

The target command enforces the control gate. The summarizer independently
checks the C++ objective using vectorized Python tables and verifies that
all selected changes are allowed. For optional image locators, Pillow and
SciPy are also needed:

```sh
python audit_lines.py f0030_L10 f0030_L12 f0032R_L12 f0032R_L13
```

`results/` retains the top twenty candidates per run. `manifest.json`
records source and artifact hashes. Generated binaries and review images
are ignored. No messages or archive requests were sent. `ROOM.md` and the
target notes are appended to; original ciphertext and solved status remain
unchanged.
