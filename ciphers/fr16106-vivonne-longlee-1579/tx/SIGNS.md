# Sign labels for the Vivonne/Longlee letter-form cipher (fr.16107 c107, 2 Mar 1580) -- VIV-T, 4 Oct 2026

Provisional reference inventory written by VIV-T from three line crops (L01, L05, L12) before any pass; descriptions
only, no plaintext values. One label per sign, space-separated. A sign not in this list: write `?{short description}`
(e.g. `?{hooked v}`); an illegible sign: `?`. Never guess plaintext.
