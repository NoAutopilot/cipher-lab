# Sign description convention (neutral; BNF-RONDI-KEY, 13 Oct 2026)
Each block is a two- or three-column list: a plain letter (or word) at the left of each row, then one or more signs.
- Figure: write the digits as seen, e.g. 15, 61. A figure with a small digit/mark above it: write `base^mark`, e.g. 14^3 (the mark is the small sign above the base figure). A digit below: `base_mark`. Overbar on figure: `~25` (bar over). Dot between figures: `.`
- Letter-like sign (looks like a letter, a cross, a curl, a zeta-like or x-like stroke): give a short descriptive name in brackets, e.g. [cross], [zeta], [x], [curl], [p-loop]; if it resembles a Latin letter write it in quotes, e.g. "u".
- Struck-out writing: wrap in <strike>...</strike>.
- Unreadable: `?`; doubtful reading: add `?` after it.
- Annotations (Italian, French, headings): copy letter for letter, keep spelling; mark doubtful letters with `?`.
- Report row by row, top to bottom, left column then right column, and say which crop each row came from.
- Do not infer meanings; do not use outside knowledge of any key. Transcribe only what the ink shows.
