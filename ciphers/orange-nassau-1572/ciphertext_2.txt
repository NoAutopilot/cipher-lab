# Lettre CCCLXXXVII, "Le Prince d'Orange au Comte Jean de Nassau. Sur la reddition de
# Mons et la position deplorable des affaires", dated "en mon camp a Geel, ce 24 de
# [7bre/septembre] 1572" -- three days after Lettre CCCLXXXV (our main target). This is
# the second letter L.J. Nepveu tot Ameyde treats in his 1842 article (pp.20-21), stating
# in his covering letter (p.18) that he found ONE key covering the cipher passages in
# BOTH CCCLXXXV and CCCLXXXVII. Djvu OCR lines 24429-24557 (djvu-text line numbers, not
# printed page numbers); printed extent approximately pp.511-514 (running heads "-- 511 --"
# at djvu line ~24457, "-- 513 --" at ~24480, "-- 515 --" at djvu line ~24555, the last
# belonging to the NEXT letter CCCLXXXVIII).
#
# IMPORTANT -- Groen printed this letter TWICE, back to back, and only the second printing
# is ciphertext (the material below). Per Groen's own editorial note (reproduced verbatim
# below, djvu lines ~24487-24490): "Le chiffre de cette Lettre etant, selon toutes les
# apparences, le meme que celui de la Lettre 384, nous le reproduisons ici, afin de
# faciliter la tache de ceux qui voudroient tenter de retablir les lacunes p.504 sqq."
# ["The cipher of this letter being, by all appearances, the same as that of Letter 384,
# we reproduce it here, to help those who would want to try to restore the gaps p.504
# sqq [i.e. in Lettre CCCLXXXV]."] -- i.e. Groen believed this letter's cipher matches
# Lettre 384 (an earlier letter, not catalogued in this repo), and printed the enciphered
# original specifically as a cryptanalytic aid for Lettre CCCLXXXV's still-unbroken
# passages. This is Groen's own 1836 statement, established fact from the primary source,
# not a claim by this worker.
#
# ESTABLISHED, NOT INFERRED: Groen's FIRST printing of this letter (djvu lines 24429-24485,
# NOT reproduced in this file) already gives the full letter in clear, unenciphered French
# ("Monsr mon frere. Depuis l'enclose escrite, j'ay entendu telles nouvelles, que je crain
# fort que mon frere Loyse soit entre les mains du Duc d'Alve et la ville rendue..."
# through "...vous y teniez la main tant que possible vous sera. Escrit en mon camp a
# Geel, ce 24 de septembre 1572. Vostre bien bon frere a vous faire service, Guillaume de
# Nassau."). Groen's 1836 edition therefore already contains a matched plaintext/ciphertext
# pair for this letter -- printed by Groen himself, six years before Nepveu's 1842 key --
# because a separate, unenciphered copy or register draft of this particular letter
# survived alongside the enciphered original sent to Jean de Nassau. This is a primary-
# source fact about Groen's 1836 print, stated here for the record; it is not a claim of
