

## Images removed from the public repository (23 September 2026)

The repository became public on 23 September 2026. Image files under terms that do not allow redistribution were removed from the tree and are re-fetchable from the URLs in manifest.json with the scripts beside it: two Koninklijk Huisarchief autograph leaves whose reuse terms were not checked; the Internet Archive page scans (public domain) stay. The manifests, crop boxes and transcriptions are unchanged. They remain in git history before this date.
