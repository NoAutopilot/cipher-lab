# PREREG R14-RJMTQ (6 Oct 2026): T and Q values from pooled alignments

Written and pushed before `scripts/pool_tq.py` is run on any page. CPU only; no new reads, no key edits, no grade change unless a gate passes.

Material (fixed): the hard-EM alignments already in this folder, unchanged --
f.194 vs f.197 and f.199 vs f.201 regenerated by scripts/test1.py's own `align()` (A/B-reconciled tokens; a split token is an @u
unknown and never counts); f.40 vs f.42 = passes/align_f40_f42.tsv; f.147-147v vs CODOIN XXVI + f.150 = passes/align_f147b.tsv
(the look-alike-settled R14-RJM9526 gated run). Only `sym` tokens labelled @T, @Q, @K count. Chunks are ia.fold()ed; an empty
chunk is a token that took no letters (a miss, never a candidate value).

Look-alike check (descriptive, done before this file from lookalike/*_tiles.tsv): Q is split against K 3 times on f.194 (A Q / B K),
against 9 three times on f.199 and against ?3 five times on f.147; T is split against the Latin group "ott" 9 times on f.199/f.194.
These split tokens are not in the alignments (they are @u unknowns), so the counts below use agreed tokens only.

Statistics and gates (per label L in {T, Q}):
1. Free value. v_L = the most frequent non-empty chunk of L over the pool (T: held-out pages f.199, f.40, f.147b only, since f.194
   is the alphabet.tsv sample; Q: all four pages, since no Q value came from f.194). h = tokens of L with chunk v_L, n = all L tokens
   in the pool. Control (shuffled alignment, can vary): 1000 seeds; on each page draw as many symbol positions as L has there,
   uniformly from all `sym` tokens of that page, keep the alignment's chunks fixed, and take the same max statistic (top
   non-empty chunk share over the pooled draw). PASS iff h/n > control p95 AND h >= 4 AND v_L is the chunk on >= 2 pages.
2. Fixed values. T = s (Tomokiyo, tt_bar), T = d (alphabet.tsv, M); Q = y (the K value, alphabet.tsv C and Tomokiyo firm):
   share of L's tokens with that chunk vs the same random-position control with the value held fixed. PASS iff share > control
   p95 AND hits >= 3 on >= 2 pages.
3. K reference (reported, not gated): K's own y-share on the pages where K is labelled, beside Q's.

Consequence: a PASS licenses the value at S at most (rule 4), written to NOTES.md and HYPOTHESES.md only; no key file is edited.
A PASS for Q = y says Q tokens read as y; it cannot tell a homophone from a K/Q reader confusion (the look-alike split above), which
only the owner's sort (ASKS 138) settles. A FAIL is a non-test if n < 8 for that label (too few tokens to clear the h >= 4 rule
and the control together); otherwise a FAIL at this transcription (reader error 0.23-0.42).
