# Copy request — British Library, Cardinal Gualterio Papers (14 volumes, Add MS 20318-20635 selection)

**Status:** waiting on you. Stage 2 (verified unsolved, conditional) — see NOTES.md's Check-solved section,
25 Sept 2026 (LANE CX): none of the 14 target shelfmarks is named in HMC's *Calendar of the Stuart Papers*
vol. I (read in full by this worker), in DECODE, in Tomokiyo's Gualterio page, or in either solver repository.

**What to request — the smallest useful pilot, not all 14 volumes at once.** This is one large BL acquisition
(Add MS 20238-20649) in which at least three companion volumes already carry either an interlinear
decipherment on the leaf (**Add MS 20244**, "Ciphers, with decipherings, occur at ff. 177, 215, 251, 260, and
276") or a reconstructed key elsewhere (D'Estrées, Add MS 20359-20361; Medinaceli, Add MS 20563 — neither of
these three is one of our 14). Before ordering any of the 14 target volumes, ask the British Library whether
their own (non-public) folio-level description for the *earliest* pair, **Add MS 20318-20319** (1700, the
start of our range), notes "decipherings" the same way 20244's does — the online catalogue snippet used by
this project's check-solved sweeps may not reproduce that note in full. If it does, request just that pair as
the pilot; if the reply is negative or inconclusive, this needs a reading-room visit (14 volumes, 1700-1730,
is too large a blind copy order).

**Why:** correspondence to Cardinal Gualterio (nuncio in Paris 1700-06, then Cardinal Protector of the Stuarts)
from French ministers, Spanish/Sardinian ambassadors and fellow cardinals, most "partly in cipher." Full list
of the 14 volumes: Add MS 20318-20319, 20338-20339, 20365-20366, 20369-20370, 20371-20380, 20416-20420,
20426-20431, 20466-20467, 20473-20474, 20510-20511, 20554-20556, 20567-20568, 20570-20571, 20634-20635. Not
digitised.

**Order via (checked 25 Sept 2026):** British Library Imaging Services online order form
(`forms.bl.uk/imaging`) or email `itemrequests@bl.uk`, quoting Add MS 20318-20319 first and asking the
decipherment-note question above. Note found this date: the Library states it "is unable to provide scanned
copies from original manuscripts" unless a microfilm surrogate exists — ask about a surrogate before assuming
a reading-room visit (Reader Pass) is the only route.
