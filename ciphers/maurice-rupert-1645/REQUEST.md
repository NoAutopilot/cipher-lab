# Copy request — British Library Add MS 18982, ff.95r-96v

**Status:** waiting on you. Open, offline-only — see NOTES.md's Verdict (verified unsolved by this worker's
own sweep, 25 Sept 2026), blocked on BL images since the 2023 cyberattack.

**What to request:** page images of British Library, Western Manuscripts, **Add MS 18982, ff.95r-96v** —
catalogued as "Letter of Henry Osborne to Prince Rupert, 10 Nov 1645 ... Partially ciphered (**with
deciphering**)." This is a sibling item in the same volume as the target cipher (Prince Maurice to Prince
Rupert, Worcester, 7 July 1645, not itself itemised in the modern catalogue — see NOTES.md), and carries a
contemporary decipherment already, making it the cheapest possible lead: if its cipher shares the target's
system, its own period key transfers directly.

**Why this folio, not the whole volume:** Add MS 18982 runs to many items (28+ catalogued 1645-1649/50); ff.95-96
is the one item known to carry a contemporary key. If the key does not match, the next-smallest useful step
would be the volume's own item list around the (uncatalogued) 7 July 1645 letter itself — not requested here,
since its exact folio is unknown (per NOTES.md).

**Order via (checked 25 Sept 2026):** British Library Imaging Services online order form
(`forms.bl.uk/imaging`) or email `itemrequests@bl.uk`, quoting Add MS 18982, ff.95r-96v. BL's own catalogue
record for this volume states digital images are "currently unavailable" (per NOTES.md's 25 Sept 2026 read);
note found this date on the BL's manuscripts-requesting guide: the Library "is unable to provide scanned
copies from original manuscripts" unless a microfilm surrogate exists — ask about a surrogate before assuming
a reading-room visit (Reader Pass) is the only route.
