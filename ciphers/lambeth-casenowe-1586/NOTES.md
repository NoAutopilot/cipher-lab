# Casenowe (A. Dufauk de) to Henri IV, [1586] — Lambeth Palace Library MS 647, f.218

Status: open

## Description

Lambeth Palace Library, MS 647, f.218 (part of the Bacon Manuscript, MSS 647-662, "Bacon, Anthony (1558-1601)",
1579-1598). Catalogue entry (verbatim, CalmView record `MSS-647-662/647/218`, confirmed 24 Sept 2026):
Title "CASENOWE (A. Dufauk de)."; Date "[1586]"; Description "Letter to HENRI IV, King of France."; Language
"French and cipher." Copies: microfilm Lambeth Palace Library MS Film 792. Part of the same fonds as U3
(above), so possibly part of the same intelligence network/key, not established this pass.

## Verdict

**open.** No solution, key, plaintext or documented attempt on MS 647 f.218 was found in any of the six
sources. Birch 1754 and the printed Lettres missives de Henri IV were both checked by name/phrase search and
do not name this correspondent or letter (not read cover to cover). A distinct, already-worked Henri IV cipher
target exists in Bourdeau's repository (Maisse, Venice, 1592-93, f.370) which is not this item and should not
be confused with it. No novelty classification made here.

**Copy status.** Needs a copy order or on-site visit — no free digitised image located this pass (same check as
