# Copy request — Lambeth Palace Library MS 647, f.218

Status: waiting on you (no free digitised image found, check-solved 24 Sept 2026).

## What to request

A page image (or a scan from the microfilm) of Lambeth Palace Library, MS 647, f.218 ("CASENOWE (A. Dufauk
de)", letter to Henri IV, King of France, [1586], "French and cipher"; part of the Bacon Manuscript, MSS
647-662).

## Why

Single folio, "French and cipher" per the catalogue's own Language field, no noted decipherment. No free image
online: same negative LUNA image-database check as MS 649 (ciphers/lambeth-bacon-649/REQUEST.md); the only
reproduction route found is a Lambeth in-house microfilm (MS Film 792).

## Routes, cheapest first

1. **Lambeth Palace Library reading room / copying service.**
   https://www.lambethpalacelibrary.info/using-the-library/registering-and-booking/. Request a scan of MS 647
   f.218 from microfilm MS Film 792.
2. **British Library Microform Research Collections** (Bacon Papers micropublication, as for MS 649).
3. **Adam Matthew Digital**, if a subscription to *Early Modern England* is already available.

If ordering both this item and MS 649 ff.490-495 from the same visit or microfilm request, batching them into
one order is more efficient than two separate ones (both are MS Film 792/793, adjacent shelfmarks in the same
fonds).
