THE ITEM
- A report in French of the Saxon envoy Ernst Christoph von Manteuffel from Berlin to Field Marshal Count Flemming,
  July 1712: Sächsisches Hauptstaatsarchiv Dresden, 10026 Geheimes Kabinett, Loc. 694/08, digitised frame 0214 (image:
  https://www.archiv.sachsen.de/digitalisate/3a83f921-9a43-485f-874b-34653ed59b68/fullsize/0214.jpg). Mostly clear French with
  short cipher groups. We applied someone else's key, a manuscript code table made by Dr. Otto Krauske in 1893 (Loc. 694/10),
  not a period key and not our own.
- One cipher run reads, with that table: "l'on me mande qu'on n'attend que [ma guérison] pour achever l'ouvrage"; the clear
  text above it says "avant que je tombasse malade". The same letter names Flemming and Manteuffel by code and a "Mons." whose
  code (110.297) we cannot read.
- Our audit and search log: https://github.com/NoAutopilot/cipher-lab/blob/main/ciphers/sachsstaatsarchiv-manteuffel-1712/AUDIT.md
  (section "AUDIT (V-MANTR8)"). Searched so far: Acta Borussica, Behördenorganisation I (1894, Schmoller and Krauske, which prints
  other extracts of these reports), Droysen, Geschichte der preußischen Politik IV.1, Briefwisseling van Anthonie Heinsius XIII-XIV.
