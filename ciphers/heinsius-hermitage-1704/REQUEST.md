# Request: heinsius-hermitage-1704 (row HU2, copies of NA 3.01.19 invnrs. 946 and 2317)

No personal data below; log the person's own archive request separately, by date and archive only, per
CLAUDE.md rule 9.

**What's needed:** photographs or digital scans of two items in the Nationaal Archief 3.01.19 (Anthonie
Heinsius correspondence archive):

1. **Inv.nr. 946** -- Sauniere de l'Hermitage's letters to Heinsius from London, including nos. 166 (26 Feb
   1704), 177 (29 Feb 1704) and 477 (30 May 1704), each printed in the edition only as a Dutch paraphrase with
   a footnote stating the cipher passage was never solved ("Gedeeltelijk in onopgelost cijferschrift" /
   "cijfer"); the actual ciphertext is not in the printed edition at all. Also worth photographing while there:
   letter no. 251 (25 Mar 1704, same inv.nr.), whose footnote ("Door Sauniere gedeeltelijk in cijferschrift
   gesteld") does not say "onopgelost" and may already be solved -- unresolved by this pass, see NOTES.md.
2. **Inv.nr. 2317** -- "Sleutel van een cijferschrift, waarschijnlijk voor correspondentie met Engeland" (a
   cipher key, c.1705, probably for correspondence with England), found this pass in the same archive's
   miscellaneous "Cijferschrift" subsection. Not confirmed to be *the* key for Sauniere de l'Hermitage's
   letters -- the editor's own title says only "probably" -- but no other English correspondent in this
   archive is a better candidate match by geography, and comparing this key against inv.nr. 946 is the
   fastest possible route to a solved reading if it matches.

**Why a request is needed:** confirmed this pass (24 Sept 2026) via the archive's own per-item JSON that both
946 and 2317 (and the two neighbouring key items, 2315 and 2316) are `"availability":"PHYSICAL","scans":[]` --
none is digitised online. Same method as heinsius-dopff-1702/REQUEST.md; see that file or
`sources/huygens/NOTES.md` for the validated method and positive control.

**Where to send it:** Nationaal Archief, The Hague, via their standard reproduction-request route. Requesting
946 and 2317 together in one visit/order is strongly preferable to two separate requests, since the value of
2317 is entirely in comparing it against 946.

**Status:** waiting on you. Stage 2 (verified unsolved) -- see NOTES.md's check-solved sweep.
