## 0032 occurrence ("X.X. oder [mark] nach G.G./C.C. ...")

- Both passes: "X.X." (two capital X, each with a period) -- clear, no disagreement.
- Both passes: "oder" -- clear.
- Both passes: the token after "oder" is a DRAWN SYMBOL, not a letter or digit: a solid
  black-filled lozenge/diamond (a square rotated ~45 degrees), same height as the surrounding
  capital letters. Pass 1: "a drawn black-filled geometric symbol -- a small solid black
  lozenge/diamond ... not a letter". Pass 2: "a drawn symbol: a solid filled black lozenge/diamond
  (a rotated square, ~45deg, filled solid black ink, not a letter)". Unanimous, unambiguous: this
  is not "K.K." and not "A.A." -- it is a non-alphabetic sigil.
- Both passes: "nach" -- clear.
- Both passes independently flag the SAME specific ambiguity for the following monogram: a pair of
  matching capital letters each followed by a period, round-looped letterform, ambiguous between
  "G.G." and "C.C." (pass 1: "could also be read as C.C., the loop is closed like G/C secretary
  form"; pass 2: "ambiguous: could read C.C. or G.G. -- the letterform is a rounded open loop with
  a short return-stroke, consistent with either secretary-hand C or G"). Two independent blind
  passes landing on the identical specific ambiguity (not just "unclear" but specifically G-vs-C)
  is itself a signal the glyph is genuinely ambiguous in this hand, not a single misreading.
- Text past "G.G./C.C." runs into a cut-off/illegible word in both passes; not settled, out of
  scope (the crop's right/lower edge).

**Settled for this occurrence:** the second mark after "X.X. oder" is a drawn diamond/lozenge sigil,
not a letter pair. The brief's framing ("K.K. or A.A.") does not apply to this occurrence at all --
it is neither.

## 0033 occurrence ("... N. mit G.G. [?] oder K.K.")

- Both passes read the same 12-number digit run before this phrase (agreeing digit-for-digit
  between the two fresh passes): 27.48.30.19.21.29.30.85.56.11.26.27. (out of scope for this span;
  noted only because both fresh passes agree, unprompted, which cross-checks the crop's legibility).
- Both passes: "...13.11.N. mit" then THREE two-letter monograms in sequence, not one ambiguous
  mark: (1) "G.G." -- both passes read this clearly, no hedge. (2) a second monogram both passes
  best-read as "A.A." but hedge differently: pass 1 flags "H.H./N.N." as the visual alternative
  (triangular/pointed apex with crossbar), pass 2 flags this letter as ambiguous but leans "A.A."
  and separately as the least-certain of the three. Both passes' BEST reading is "A.A.". (3) "K.K."
  -- both passes read this clearly, no hedge.
- Both passes: "oder" appears ONLY between the 2nd and 3rd monogram, not between the 1st and 2nd:
  "G.G. A.A. oder K.K." (pass 1 explicit: "No oder appears between G.G. and A.A."; pass 2 matches
  the same order and placement).

**Settled for this occurrence:** this is not a single ambiguous mark read two different ways by
bMALX's original passes -- bMALX pass A ("GG. A.A.") and pass B ("G.G. oder K.K.") each caught a
different two of the same three-monogram list. The full phrase is "G.G. A.A. oder K.K." (three
codes, "oder" linking only the last two), reconciled from two fresh independent blind reads that
agree on the count, the order, and the placement of "oder"; the middle monogram's exact letter
(A.A. vs H.H./N.N.) is the one residual, M-grade ambiguity, not the G.G./K.K. vs A.A. question the
brief posed.
