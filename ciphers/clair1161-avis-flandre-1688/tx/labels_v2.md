# Sign labels v2 (READ2-C1161, 3 Oct 2026): settled from the c186R reconciliation

One label per sign, ASCII. `NEW:<description>` only if nothing fits. '/' = a light diagonal slash (keep it).

| label | shape |
|---|---|
| q | q: round bowl with a LONG straight descender, nothing across the descender |
| qb | q whose long descender is CROSSED by a short horizontal bar (dagger foot). Very common. |
| 9 | 9: bowl with only a short tail, no long descender (check the crop bottom before choosing 9 over q/qb) |
| e | epsilon ε: small, two open curves opening right |
| ee | looped Latin e (ℯ), larger, closed loop |
| c | small superscript c / ɛ hook, raised |
| th | θ: small oval crossed by a horizontal bar sticking out both sides |
| + | plain cross |
| dia | a cross with a filled diamond / blob at the centre |
| to | cross immediately followed by a small raised o, written as one unit (+o) |
| p | p-shape: tall stem with a small bowl on the upper right |
| phi | φ: circle with a vertical stroke through it |
| psi | ψ: trident / U with a central stroke |
| w | small w |
| wb | w with a bar above it (ϖ) |
| y | cursive y/ɣ: two strokes, right one descending and curling left (like 'ꝩ') |
| S | hooked S (like 'ʃ' bent into an S, descending tail curling left) |
| ls | very tall long-s / integral, from well above to well below the line |
| sd | small ʃ/i with a dot above |
| z | z with a bar through it (ƶ) |
| iii | three short vertical strokes, with or without a bar across |
| iib | two vertical strokes with a bar across (#) |
| tz | 't' over 'ʒ' composite: bar on top, z/3-like body below (like 'ꞔ'/'tj') |
| K | ornate R/K-shape with a loop (Ꝁ / ꝶ) |
| rot | r-rotunda-like hook fused to an 8 or loop (the '+ꝶ8' sign) |
| L | large looped capital L-shape |
| eloop | large looped ℰ / 2-shape with a long underline |
| rc | big line-final flourish: a cursive r-curl followed by a c (ꝶc), usually at line ends |
| box | small closed square □ |
| sqc | square open at the right (⊏) |
| 6r | '6' with an r-like hook attached on the right (6ɼ), one sign |
| d | d with a bar across its ascender (đ), usually raised |
| a o x l f | small a, small raised o, x, small ɩ/l, f with descender |
| 0 2 3 4 6 7 8 | digits as written ('77' = two signs 7 7; '3' includes ʒ; '2' with a hook arc) |
