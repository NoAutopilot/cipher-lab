# Provisional sign labels, c186R cipher block (READ2-C1161, 3 Oct 2026)

Built by eye from the c186R block overlay; one shared set for both blind passes. ASCII labels, one per sign.
Add a new label only when no row fits: `NEW:<short description>`.

| th | theta: small oval crossed by a horizontal stroke that sticks out on both sides |
| + | plain cross / plus sign |
