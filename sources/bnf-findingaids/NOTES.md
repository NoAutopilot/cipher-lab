# BnF finding-aid snapshots (archivesetmanuscrits.bnf.fr)

Unmodified HTML of BnF Département des Manuscrits notices, one file per notice ark (`<date>/<ark>.html`), fetched with
`tools/bnf_findingaid.py --save-html` (simple-search POST for the exact cote, then the notice page; descriptive
User-Agent, about 2 s between requests). Parse offline with `python3 tools/bnf_findingaid.py --html <file>`.
One notice can cover a run of volumes (cc504266 = Français 3974-3995, Collection Mémoires de la Ligue, 2,299 items).
First fetched 7 Oct 2026 by the BNF-FOCUS lane (BNF-VALUE.md section 2-3). Do not edit; refetch into a new dated folder.
