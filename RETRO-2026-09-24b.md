`tools/room.py --start` has one gap worth fixing before it is made the default first action: it checks
`git status --porcelain` (uncommitted changes) before force-checking-out `main` onto `origin/main`, but never
checks `git log origin/main..main` for *committed, unpushed* local commits — a container that boots with real
unpushed work and a clean working tree would have it silently orphaned by `checkout -B`, with no `preserve/`
branch the way the original 23 Sept incident got (a worse failure mode than the one it replaces, because that
one at least stopped and asked). Add the check:

```diff
--- a/tools/room.py
+++ b/tools/room.py
@@ def start():
     sh("git", "fetch", "-q", "origin", "main")
     r = sh("git", "status", "--porcelain")
     if r.stdout.strip():
         print("working tree has changes; not resetting. Commit or stash them first."); return 2
+    ahead = sh("git", "log", "--oneline", "main..origin/main" if sh("git","rev-parse","--verify","-q","main").returncode==0 else "HEAD", check=False)
+    unpushed = sh("git", "log", "--oneline", "origin/main..HEAD")
+    if unpushed.stdout.strip():
+        stamp = time.strftime("%Y%m%d%H%M%S", time.gmtime())
+        branch = f"preserve/{stamp}-unpushed-local-history"
+        sh("git", "branch", branch)
+        print(f"local HEAD had commits not on origin/main; saved to {branch} before resetting. Push it or ask.")
     sh("git", "checkout", "-q", "-B", "main", "origin/main")
```
