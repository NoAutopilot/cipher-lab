METHOD.
1. Positive control (synthetic, dev only). It replaces the T50 curled-Ce case, which was picked because it was known to be reachable. Make 20 seeded corruptions on dev_tune lines: choose a pile of >= 3 positions, relabel all its positions to the read sign's top confusion neighbour, and run the tool. Gate P: the corrupted pile is restored (to the original sign or a same-value homophone) in >= 12 of 20, AND false acceptances on uncorrupted piles average <= 1 per run. STOP before eval if P is not met.
2. Look-alike control. For each (p,c) the tool accepts on dev, relabel the same pile to a random non-neighbour key sign. The acceptance rate on these must be <= 0.05.
3. Real dev (dev_tune, scored): net >= 0 against passC. Otherwise STOP.
4. Commit the outputs, the per-pile tables and the sha256. Add the LOOKS.tsv rows. Take one eval look.

ENDPOINT AND GATE. Score with tools/tx_bench.py --exclude-flagged --strict --paired <base>, both masks, with Wilson intervals, on no.87 eval_heldout (376 / 371) and f152r (73 / 70), separately and pooled. Gate:
- pooled fixed > broken, exact two-sided p < 0.05, at value level;
- AND the real net > the 95th percentile of the shuffled-key arm (the whole tool run with each of the 20 shuffled keys used as if it were real);
- AND --strict is not worse than the base on either item. A relabel to a same-value homophone is a value fix, not a visual one: report how many of the fixes are strict fixes.
- AND the real net > the 95th percentile of a shuffled-cluster arm: the whole tool run with the cluster ids permuted among the positions of the same read sign, 20 seeds. This is the chance null for the machine grouping (R4a).
Report every figure twice: on all positions, and with the no.87 eval_heldout positions that TXE3-10's d/s classifier fixes set aside. Say how many of the tool's fixes fall on those positions. A pass that rests on them is 'weak: the d/s pile only'.
CONTROLS AND WHY THEY CAN VARY. The shuffled-key arm changes every Delta. The random-alternative arm changes c. The shuffled-cluster arm keeps the read signs and the pile sizes but breaks the shape grouping, so its acceptances can differ from the real arm's. The synthetic positive control shows the tool can see a planted pile error at all.
