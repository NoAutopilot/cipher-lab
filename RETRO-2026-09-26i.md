## 1. A landing worker can silently truncate a shared file to a stub, on a plain `git commit` outside `room.py`,
   with no ROOM.md trace at all -- the existing shrink guards do not cover this shape or this path

`tools/room.py`'s `room_ok()` guards ROOM.md's own line count and `headings_ok()` guards STATUS.md/QUEUE.md's `##`
headings, but both only run inside `room.py --push`. A worker that runs a plain `git commit` + `git push` (as
PR-LAND-3 did, and as most content-committing workers do -- LADDER-TOOL's own `c20af04` this same window is a
plain commit) bypasses every guard that exists. Nothing anywhere checks that a tracked file's line count or byte
size did not collapse to near-zero relative to its previous committed version, for any file, on any push path.
Separately, nothing checks that the committing session's own name appears anywhere in ROOM.md -- the "claim
before work, done when stopping" rule (CLAUDE.md "Workers") is prose only, unenforced by any tool, which is why a
worker can skip it entirely and nobody notices until a human (or, here, another worker) reads the file by chance.

```diff
--- a/tools/room.py
+++ b/tools/room.py
@@ (near headings_ok, add a sibling check)
+def shrink_ok(before_sizes, paths):
+    """For each path in `paths` (files this commit touches, from `git diff --cached --name-only` or the commit
+    range being pushed), compare line count against `before_sizes[path]` (captured pre-commit the same way
+    headings_ok() snapshots headings pre-rebase). Flag any path whose line count drops below 20% of its prior
+    count AND drops below 5 lines absolute (a real shrink -- AX2-SHRINK-style image-folder edits and legitimate
+    file truncations stay well above 5 lines, or are named in the commit message with 'shrink'/'regen'/'restore'/
+    'AX2-SHRINK', which this function exempts by checking HEAD's own commit message via `git log -1 --format=%s`).
+    Returns the list of (path, before, after) triples that failed, same shape as headings_ok()'s return. Refuse the
+    push and name the file(s), same as the existing ROOM.md/STATUS.md/QUEUE.md guards (26 Sept 2026, PR-LAND-3:
+    `LOCAL-QUEUE.tsv` 26->1 lines and `ciphers/bl-charles-digby/AUDIT.md` 119->1 lines, both on a plain `git
+    commit` that never called room.py at all, so this check must also run as a standalone pre-push script a
+    worker's brief can require, not only inside room.py --push).
+    """
```
