## Top pick

**A methodological gap, not a single target: rounds 1-4's `tools/ia_numeral_runs.py` detector (QUEUE.md
"Printed ciphertext" sections) can only find cipher passages where the edition prints the raw cipher digits
themselves.** It structurally cannot see an edition whose convention is to replace an undeciphered cipher
passage with a bracketed editorial note in running prose -- no digits on the page at all for the detector to
count. A plain Google Books phrase search for the editor's own annotation (`"cifra no descifrada"`, `"cifra non
decifrata"`, etc.) surfaces exactly this second category, genuinely unswept by rounds 1-4 and by the
correspondence-edition sections (3630, 3913), which used site-specific note-field searches (EMLO's `bibo_Note`,
Huygens's `opmerkingen`) rather than a general phrase sweep. Two candidates below (D1, D2) come from this route.
**Caveat that keeps this from being a clean pick, not a maybe:** in every snippet found this session, the
annotation sits *inside* a sentence with no visible digits before or after it -- consistent with the editor
having *omitted* the cipher figures from print entirely, not merely left them undeciphered beside the text (the
Thurloe/Stuart-Papers/Rikskansleren pattern that rounds 1-4 correctly caught). **Neither D1 nor D2 has been
confirmed to have recoverable ciphertext on any page** -- that confirmation (one page-image or full-volume-text
check) is the necessary first step before either is a "cheap test with a control," and is cheaper than a
campaign: check first, transcribe only if digits exist.
