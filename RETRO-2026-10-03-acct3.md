### Proposal 2 -- the vision-call line becomes a gate (Usage 8a: 0 of 119 image briefs carry it, 76 cite "priced per pass" with no number)

New `tools/brief_price_check.py` (offline test in `tools/tests/test_brief_price_check.py`), run by the orchestrator
on every brief before `create_session`:

```diff
+#!/usr/bin/env python3
+"""Gate: a brief that sends images to a model states its vision-call count and per-call price (Usage 6, README
+"Vision calls are a counted unit"; RETRO-2026-10-03-acct3 proposal 2).
+
+Catches: a brief under .claude/briefs/runs/ whose text names an image step (blind pass, crops, tiles, reader,
+gloss read, transcribe, iiif_lines) but has no line matching
+    vision calls: <N> x USD <r> [+ <k> reconciliation] = <X>
+and, when one exists, X greater than the brief's "Cap USD <c>" (exit 1 either way).
+Must NOT block: a brief with no image step (a gate-fix, a print check, a family_run on disk data), or a brief that
+says "no images" / "disk only" with no image verb (tests cover both, plus F36-GLOSS's own text as the failing case).
+Rates: Sonnet about USD 1.5 a call on native crops (AX-COMP2); Opus has no recorded rate -- the brief writes
+"Opus rate unmeasured: first call measured and reported, stop if over USD 3" and the gate accepts that wording.
+"""
+import re, sys
+IMG = re.compile(r'blind pass|\bcrops?\b|\btiles?\b|\breaders?\b|gloss read|transcri|iiif_lines|vision', re.I)
+LINE = re.compile(r'vision calls:\s*(\d+)\s*x\s*USD\s*([\d.]+)(?:\s*\+\s*(\d+)\s*reconciliation)?\s*=\s*([\d.]+)', re.I)
+NOIMG = re.compile(r'\bno images?\b|\bdisk only\b', re.I)
+OPUS_UNMEASURED = re.compile(r'Opus rate unmeasured', re.I)
+CAP = re.compile(r'Cap (?:USD |\$)?([\d.]+)')
+def check(text):
+    if not IMG.search(text) or (NOIMG.search(text) and not re.search(r'blind pass|transcri', text, re.I)):
+        return 0, 'no image step'
+    m = LINE.search(text)
+    if not m and not OPUS_UNMEASURED.search(text):
+        return 1, 'image step but no "vision calls: N x USD r = X" line'
+    cap = CAP.search(text)
+    if m and cap and float(m.group(4)) > float(cap.group(1)) * 1.0001:
+        return 1, f'vision calls price {m.group(4)} exceeds cap {cap.group(1)}'
+    return 0, 'ok'
+if __name__ == '__main__':
+    worst = 0
+    for p in sys.argv[1:]:
+        rc, why = check(open(p).read()); worst = max(worst, rc); print(f'{p}: {"FAIL" if rc else "ok"} -- {why}')
+    sys.exit(worst)
```
